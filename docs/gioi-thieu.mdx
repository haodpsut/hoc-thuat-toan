# Học thuật toán bằng hình ảnh

Đây là một dự án **tiếng Việt, mở và miễn phí** giúp học tư duy lập trình và thuật toán bằng cách
tương tác trực tiếp: nhìn thuật toán chạy từng bước, chạy code Python ngay trong trình duyệt, và
tự luyện tập với bài tập có chấm tự động.

Mỗi bài học gồm năm phần:

1. **Ý tưởng** trình bày ngắn gọn, dễ hiểu.
2. **Trực quan hoá** sinh theo dữ liệu bạn nhập, có thể tua từng bước.
3. **Chạy code Python** thật, xem từng dòng và từng biến thay đổi.
4. **Phân tích độ phức tạp** kèm số liệu đo thực tế.
5. **Luyện tập** với bộ chấm tự động ngay trên trang.

Bạn không cần cài đặt gì. Mọi thứ chạy trong trình duyệt.
